## [0.1.0]

### Added
- Product list with add, edit and delete
- Search by name or SKU
- Low-stock highlighting and status-bar count
- Validation: required fields, non-negative numbers, unique case-insensitive SKUs
- SQLite storage in `%LOCALAPPDATA%\StockKeep`
- xUnit test suite for `StockKeep.Core`
- GitHub Actions CI (build + test on every pull request)
