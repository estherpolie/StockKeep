# Code of Conduct

## Our standard

StockKeep aims to be a friendly, welcoming project for everyone, whatever their experience level, background or identity.

**Expected behaviour**
- Be respectful and constructive, especially in code reviews. Critique the code, not the person.
- Assume good intent and ask questions before drawing conclusions.
- Keep discussions on topic.

**Unacceptable behaviour**
- Harassment, insults, or discriminatory language
- Personal attacks or trolling
- Repeated off-topic or spam posts
- Publishing others' private information

## Enforcement

Maintainers are responsible for applying this Code of Conduct. Actions are proportional and usually follow these steps:

1. **Correction:** a private or public reminder that links to this document.
2. **Warning:** a written warning stating what must change and what happens next.
3. **Temporary ban:** a time-limited block from interacting with the project.
4. **Permanent ban:** for serious or repeated violations.

Threads that become unproductive may be locked. Every enforcement action is recorded privately by maintainers, with the date, the rule involved and the action taken, so decisions stay consistent.

## Reporting

Report problems privately to the maintainer via the contact details on the [maintainer's GitHub profile](https://github.com/estherpolie). All reports are reviewed and kept confidential.

This Code of Conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
